# Discourse

Plateforme de forum moderne et auto-hébergée, la référence mondiale des forums communautaires.

## Accès
- **URL** : http://localhost:4000
- **Identifiants par défaut** : admin / discourse-admin (email : admin@example.com)

## Notes
- Le premier démarrage peut prendre 2–3 minutes (initialisation de la base de données).
- Configurez un serveur SMTP réel pour activer les notifications par email.
- Changer le mot de passe admin depuis l'interface après le premier démarrage.
