Prebuilt Images

Releases ship registry/index.tsv in the Store archive plus one prebuilt image pack per app (dockan-store-images-APP_ID.tar.gz). Images are imported locally into Dockan on demand.

./dockan-store images APP_ID
./dockan-store build-images all
DOCKAN_STORE_FORCE_IMAGES=1 ./dockan-store images APP_ID

CLI & Dockan Panel Install

Dockan Panel automatically downloads the Store and installs apps under /srv/dockan-apps/APP_ID (root) or ~/dockan-apps/APP_ID with DOCKAN_PORT_BIND_ADDR=0.0.0.0.

./dockan-store install APP_ID
cd ~/dockan-apps/APP_ID
dockan compose up
dockan compose health
sudo dockan compose autostart -f dockan.yml

Update Installed Apps

Use update to import fresher image packs while keeping your existing volumes and local dockan.yml configuration intact.

./dockan-store update APP_ID /srv/dockan-apps/APP_ID

# Or directly with Dockan Core:
dockan pull IMAGE:local registry
dockan compose redeploy -f /srv/dockan-apps/APP_ID/dockan.yml
